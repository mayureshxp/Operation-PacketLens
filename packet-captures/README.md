Packet Capture Files

This folder contains the packet capture files generated during the three Operation PacketLens experiments using Wireshark.

Experiment 1 — TCP Handshake and HTTP Analysis

Capture file: "OPD_PacketLense_01"

Analysis includes:

- TCP SYN, SYN/ACK and ACK handshake
- HTTP GET request
- HTTP 200 OK response
- TCP connection termination

Experiment 2 — DNS Query and Response Analysis

Capture file: "ODP_02_DNS_Analysis"

Analysis includes:

- DNS queries for example.com
- A record (IPv4) responses
- AAAA record (IPv6) queries and responses

Experiment 3 — ICMP Connectivity Testing

Capture file: "OPD_03_ICMP_Connectivity_Test"

Analysis includes:

- ICMP Echo Request packets
- ICMP Echo Reply packets
- Connectivity testing to 1.1.1.1

Tool: Wireshark

These captures provide packet-level evidence of the network protocols examined during the project.
